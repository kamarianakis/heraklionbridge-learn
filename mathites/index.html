Για μαθητές

Υλικό για όσους παρακολουθούν τα μαθήματα του Ομίλου: δείτε ξανά την ύλη κάθε ενότητας και δοκιμάστε τις γνώσεις σας. Οι ενότητες είναι αριθμημένες (01, 02, 03…) με τη σειρά που πρέπει να τις ακολουθήσετε: κάθε ενότητα χτίζει πάνω σε όσα έχουν προηγηθεί.

Για όσους έλειψαν ή θέλουν επανάληψη Διαφάνειες μαθημάτων Η ύλη κάθε ενότητας βήμα βήμα, με παραδείγματα και διαγράμματα του τραπεζιού. Δουλεύουν σε υπολογιστή, tablet και κινητό. Δείτε τις διαφάνειες → Δοκιμάστε τις γνώσεις σας Κουίζ μαθημάτων Ένα διαδραστικό κουίζ για κάθε ενότητα, με άμεση απάντηση και εξήγηση. Μπορείτε να παραλείπετε ερωτήσεις και να γυρίζετε πίσω.
